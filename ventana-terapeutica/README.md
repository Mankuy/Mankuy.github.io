# Ventana terapéutica

Simulador educativo de **una sesión de psilocibina**, seguida 14 días.

La molécula abre. La plasticidad se queda. El viaje es la llave; esto es la casa.

**En vivo:** [mankuy.github.io/ventana-terapeutica](https://mankuy.github.io/ventana-terapeutica/)

No es consejo clínico ni una calculadora de dosis. Es una pieza para mirar juntos: occupancy 5-HT2A (Madsen 2019), REBUS (Carhart-Harris), plasticidad crítica (Nardou 2023), cepas, cohorte, el día y el cuerpo, y el laboratorio de la ventana.

Vanilla JS, sin build. Las mallas del cerebro son obra derivada de BodyParts3D (CC BY-SA 2.1 Japón); ver `modelo/LICENCIA.txt`.
